# 메모리 반도체 뉴스런 스킬 (memory-semi-newsrun)

메모리 반도체(DRAM, NAND, HBM) 뉴스를 **한국, 대만, 중국, 일본** 매체에서 찾아 **업체별로** 정리하는 Claude 스킬입니다.
하루 두 번(오전 10시 30분, 오후 5시) 실행하며, 회차마다 앞 회차 이후의 새 기사만 모읍니다.
과거 보도와 달라진 내용이나 정정 보도는 따로 뽑아 **이전과 지금을 비교**해 보여줍니다.

## 설계 구조

SKILL.md는 6가지 관점으로 구성했습니다.

| 관점 | 내용 |
|---|---|
| **Role** | 메모리 업계 담당 애널리스트. 독자는 업계 실무자, 5분 안에 변화를 파악하는 것이 목표 |
| **Context** | 대상 업체 10곳, 4개 언어 키워드, 회사별 세대 명칭(1γ, BiCS8 등), 국가별 매체, 수집 구간 |
| **Tools** | 웹 검색, 페이지 열기, 파일 저장. 2단계 검색 예산(넓게 → 깊게)과 회차 간 기록 저장 위치 |
| **Workflow** | 준비 → 1차 검색 → 2차 검색 → 본문 확인 → 거르기 → 묶기 → 변경 확인 → 작성 → 자가 점검 → 저장 |
| **Rubric** | 헤드라인 중요도 기준(영향, 확실성, 새로움)과 12개 항목 자가 점검 체크리스트 |
| **Guardrail** | 정확성, 저작권(요약만, 원문 복사 금지), 투자 조언 금지, 웹 페이지 속 지시문 무시 |

## 주요 기능

- **대상 업체**: 삼성전자, SK하이닉스, 마이크론, 키옥시아, 샌디스크, 솔리다임, YMTC, CXMT, ASML, 엔비디아
- **매체**: 한국 전체(디일렉, 전자신문 중점), 대만 DigiTimes, 중국·일본 주요 언론 5곳과 IT 매체
- **수집 구간**

  | 회차 | 수집 구간 |
  |---|---|
  | 오전 10시 30분 | 전날 17:00 ~ 오늘 10:30 |
  | 오후 5시 | 오늘 10:30 ~ 오늘 17:00 |

  오전 회차를 10시 30분으로 둔 이유: 국내 조간과 오전 기사, 중국·일본 오전 기사까지 반영하기 위해서입니다. 오후 회차를 5시로 둔 이유: 일본 기업의 공시와 실적 발표가 장 마감(15시) 이후에 나오고, 중국과 국내 오후 기사가 쌓일 시간을 두기 위해서입니다.

- **새 뉴스만**: 구간 밖 기사와, 직전 회차에서 다룬 뉴스를 늦게 받아쓴 기사는 뺍니다.
- **중복 제거**: 같은 사건은 하나로 묶고 나머지 매체는 이름만 적습니다.
- **오늘 일정**: 실적 발표, 인사 발표처럼 오늘 예정된 대상 업체 일정을 따로 보여줍니다.
- **첫 실행**: 기록이 없는 첫 실행은 최근 48시간을 모읍니다.
- **변경·정정 하이라이트**: 일정, 숫자, 계약, 결정이 최근 45일 보도와 달라지면 `[변경]`, 정정 보도나 공식 부인은 `[정정]`, 루머가 공식 확인되면 `[확정]`으로 표시하고 맨 위에 이전과 지금을 나란히 보여줍니다.

## 폴더 구성

```
memory-semi-newsrun/
├── SKILL.md                    # 스킬 본체 (Role, Context, Tools, Workflow, Rubric, Guardrail)
└── references/
    ├── sources.md              # 국가별 매체
    ├── keywords.md             # 업체명·키워드 4개 언어 표기, 회사별 세대 명칭
    ├── output-template.md      # 결과물 양식과 예시
    └── history-format.md       # 회차 간 기록 파일 형식
```

실행하면 작업 폴더에 아래 기록이 쌓입니다. `.gitignore`로 저장소에는 올리지 않게 해 두었습니다.

```
newsrun-data/
├── history.md                  # 변경 비교와 중복 제거용 기록
└── reports/                    # 회차별 보고서
```

## 사용 방법

1. `memory-semi-newsrun` 폴더를 zip으로 압축합니다.
2. Claude 설정의 **Capabilities → Skills**에서 zip 파일을 업로드합니다. (Claude Code는 `~/.claude/skills/` 폴더에 넣으면 됩니다.)
3. 웹 검색을 켜고, 기록을 남길 폴더를 연결한 뒤 이렇게 요청합니다.
   - "반도체 뉴스런 해줘"
   - "10월 27일부터 29일까지 HBM 뉴스런 해줘" (기간 직접 지정)
4. 매일 자동으로 받으려면 예약 작업으로 오전 10시 30분, 오후 5시에 "반도체 뉴스런 해줘"를 실행하도록 설정합니다.

## 맞춤 설정

- 업체, 키워드, 세대 명칭: `references/keywords.md`
- 매체: `references/sources.md`
- 결과물 형식: `references/output-template.md`
- 실행 시각, 검색 예산: `SKILL.md`의 Tools, Workflow 섹션
